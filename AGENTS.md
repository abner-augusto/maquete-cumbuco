# AGENTS.md

Maquete interativa 3D (Three.js) do loteamento Cidade das Américas — Residencial Cumbuco, Fase 1 (Cancun), para venda de lotes. Publicada como Worker de assets estáticos no Cloudflare e usada offline via `iniciar.cmd`.

## Language

Docs, `GLOSSARY.md`, UI text, and commit messages are Brazilian Portuguese.

## Commits

Use Conventional Commits: `tipo(escopo opcional): descrição`. Mantenha os tipos convencionais em inglês (`feat`, `fix`, `docs`, `refactor`, `chore`) e escreva a descrição em português brasileiro. Exemplo: `feat(rotatoria): adiciona monumento com praça central`.

## Design

The design spec lives in `docs/superpowers/specs/`. Read it before changing scope, data rules, or the pipeline.

## Sources of truth

- Lot geometry, cadastre, prices, and media are read from the terrain folder pointed to by `TERRENO_DIR` in `.env`. Never copy a number into the front by hand: regenerate `dados/` with the scripts.
- The Blender model is generated by script. Fix the script and rerun it; never hand-edit the generated `.blend`.
- `frontend/public/` is generated by `npm run assets` (except `public/_headers`); never edit it by hand.
- Domain notes live in the Obsidian vault: `$VAULT_DIR\01-Projects\Brasil Incorporadora\Cumbuco - CE\`.

## Reference repos

- `$REPOS_DIR/cv_espelho_vendas`: front skeleton, entorno pipeline, e2e tests, Worker deploy.
- `$REPOS_DIR/UFCIM-FRONT3D`: touch gesture mapping for the camera.

## Confidentiality

The active brand name is "Cidade das Américas" (`FAMILIAS`/`ATIVA` in `scripts/marca/familias.py`). The "alternativa" family (a placeholder for the held name) is kept only for marketing validation until the name is registered: the real name must not appear in the site, the active brandbook, or anything published, and it is not in this repository. `NOME_PROIBIDO` in `.env` lists the held name(s); `npm run build` (verificar-dist) fails if one shows up in `dist/`. Do not publish a public, indexable URL without the user's explicit go-ahead.
