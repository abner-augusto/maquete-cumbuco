# Triage labels

| Papel | Texto do status | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | O Abner precisa avaliar |
| `needs-info` | `needs-info` | Esperando mais informação |
| `ready-for-agent` | `ready-for-agent` | Especificado por inteiro; um agente faz sem gente |
| `ready-for-human` | `ready-for-human` | Pede decisão ou trabalho de mão do Abner |
| `wontfix` | `wontfix` | Não será feito |

Trabalho em andamento usa `claimed`; trabalho concluído usa `done`.
